Audit and fix the URL canonicalization setup across the entire HarmonyBreath Astro website.

Goal:
Use one consistent canonical URL format for every real page:
https://harmonybreath.com/<path>/

The homepage should be:
https://harmonybreath.com/

Important: Do NOT change page content, titles, descriptions, keywords, schema content, layout, analytics, cookie consent, or SEO strategy. Only fix URL consistency/canonicalization.

Tasks:

1. Audit every Astro page in src/pages/ and determine its actual public URL.

2. Use trailing-slash URLs consistently for all HTML pages.

Expected canonical URLs include:
- https://harmonybreath.com/
- https://harmonybreath.com/about/
- https://harmonybreath.com/wim-hof/
- https://harmonybreath.com/box-breathing/
- https://harmonybreath.com/4-7-8-breathing/
- https://harmonybreath.com/contact/
- https://harmonybreath.com/privacy/
- https://harmonybreath.com/terms/
- https://harmonybreath.com/quotes/
- https://harmonybreath.com/diaphragmatic-breathing/ (if this route exists)

Use the actual existing route names in the project. Do not invent or rename routes.

3. Fix Layout.astro canonical handling.

Every indexable page must output a self-referencing canonical URL using its exact preferred trailing-slash URL.

For example:
<link rel="canonical" href="https://harmonybreath.com/wim-hof/" />

Do NOT make technique pages canonical to the homepage.

4. Audit every page that passes canonicalUrl to Layout.astro.

Make sure the value matches the actual preferred URL exactly, including:
- https
- harmonybreath.com
- correct path
- trailing slash

5. Audit the sitemap.xml.

Every real indexable page should appear in the sitemap using its exact canonical URL.

For example:
<loc>https://harmonybreath.com/wim-hof/</loc>

Do not put non-canonical variants such as:
http://harmonybreath.com/
https://harmonybreath.com/about
https://harmonybreath.com/wim-hof

Do not include pages that are intentionally noindex.

6. Audit internal links.

Wherever the site links to its own pages, use the preferred canonical trailing-slash URLs.

Examples:
href="/wim-hof/"
href="/box-breathing/"
href="/4-7-8-breathing/"
href="/about/"

Do not change external links.

7. Check robots/indexability.

Make sure all intended public content pages have:
<meta name="robots" content="index, follow">

Do not accidentally add noindex to normal HarmonyBreath pages.

Keep the existing noindex behavior for the Cloudflare pages.dev domain. Do NOT remove:
X-Robots-Tag: noindex
from pages.dev/preview deployments.

8. Do NOT try to eliminate legitimate redirects.

The following behavior is acceptable and should remain:
http://harmonybreath.com/ → https://harmonybreath.com/
https://www.harmonybreath.com/ → https://harmonybreath.com/
https://harmonybreath.com/about → https://harmonybreath.com/about/
https://harmonybreath.com/wim-hof → https://harmonybreath.com/wim-hof/
etc.

The goal is not to remove redirects. The goal is to ensure redirects point to the correct canonical URL and that sitemap/canonical/internal links all use the destination URL.

9. Check for accidental duplicate routes.

Look for pages or links that could create duplicate URLs such as:
- http vs https
- www vs non-www
- trailing slash vs non-trailing slash
- old route names
- duplicate Astro routes

Do not delete anything unless it is clearly an accidental duplicate. Report anything uncertain instead of guessing.

10. Verify the build.

Run:
npm run build

Then inspect the generated dist/ output.

Confirm:
- Every intended page exists.
- Canonical tags are correct.
- Sitemap contains the correct URLs.
- No important page has noindex.
- No canonical points to the homepage accidentally.

11. Before making changes, show me a short audit table:

Page | Actual route | Current canonical | Expected canonical | Sitemap | Status

Then make only the necessary changes.

At the end, summarize:
- files changed
- canonical URLs fixed
- sitemap changes
- internal links fixed
- anything that was intentionally left unchanged
- build result

Do not modify unrelated functionality.
