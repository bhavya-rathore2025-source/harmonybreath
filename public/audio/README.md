# HarmonyBreath Audio Directory

Audio files for the three-phase breathing exercise. Place or replace custom audio files in this directory.

## Phase 1 — Guided Breathing (30 Breaths)

| File | Description |
|------|-------------|
| `guided-breathing.mp3` | Default guided 30-breath rhythmic audio |
| `guided-breathing-calm.mp3` | Gentle ocean waves for relaxed breathing |
| `guided-breathing-forest.mp3` | Peaceful forest sounds for grounding |
| `guided-breathing-minimal.mp3` | Subtle bell tones for focused breathing |
| `guided-breathing-ambient.mp3` | Deep ambient drone for trance states |

## Phase 2 — Breath-Out Hold (Retention)

| File | Description |
|------|-------------|
| `breath-out-hold.mp3` | Default calm background for retention hold |
| `breath-out-hold-silence.mp3` | Pure silence for deep internal focus |
| `breath-out-hold-drone.mp3` | Low frequency drone for extended retention |
| `breath-out-hold-bowl.mp3` | Crystal bowl tones for meditative holds |

## Phase 3 — Recovery Hold (15s)

| File | Description |
|------|-------------|
| `recovery-hold.mp3` | Default 15-second recovery guidance |
| `recovery-hold-chime.mp3` | Gentle chimes for recovery inhale & hold |
| `recovery-hold-silence.mp3` | Quiet space for natural recovery breath |
| `recovery-hold-ambient.mp3` | Warm ambient pad for gentle recovery |

## Utility Sounds

| File | Description |
|------|-------------|
| `chime.mp3` | Soft chime for phase transition cues |
| `breath-inhale.mp3` | Inhale breath sound cue |
| `breath-exhale.mp3` | Exhale breath sound cue |

If any files are missing, HarmonyBreath handles it gracefully — the timer runs visually and silently without errors.
