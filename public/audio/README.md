# HarmonyBreath Audio Directory

Place your custom audio files in this directory:

- `guided-breathing.mp3` — Played during Phase 1 (30 Breaths)
- `breath-out-hold.mp3` — Played during Phase 2 (Retention Hold)
- `recovery-hold.mp3` — Played during Phase 3 (15s Recovery Hold)
- `chime.mp3` — Played on phase transition cues

If any of these files are missing, **HarmonyBreath handles it gracefully** by running the breathing timer visually and silently without errors!
